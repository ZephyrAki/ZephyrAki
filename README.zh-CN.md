## 关于我

我是 **Zephyr**，一名软件技术专业的学生，喜欢把想法变成真正能用的软件。

我对应用开发、自托管服务和 AI 工具都很感兴趣：从 Java、Android，到 Linux、部署与自动化。我习惯通过实际动手来学习，先做出来，再弄清楚它为什么能运行，然后一点点改进。

- 🛠️ 维护 **Mineradio macOS 版**，这是基于原项目的非官方适配与维护版本。
- 🌐 在 **[zephyraki.online](https://zephyraki.online)** 建设自己的个人博客。
- 🤖 探索 **MCP、AI 智能体和实用的自动化工作流**。
- 🌱 学习 **Java / Spring、Android、数据库设计和后端架构**。

> 先让它运行起来，理解它为什么能运行，再把它做得更好。
